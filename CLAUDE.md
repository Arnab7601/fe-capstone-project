# Frontend Capstone Project Rules & Conventions

## Tech Stack
- Framework: React / Next.js (TypeScript)
- Styling: Tailwind CSS
- State Management: React Context / Hooks
- Package Manager: npm

## Coding Conventions
- Use functional React components with standard React Hooks.
- Maintain modular file structure with reusable UI components in `/components`.
- Write semantic, accessible HTML (WCAG compliant).
- Use Conventional Commits format for Git commits (`feat:`, `fix:`, `docs:`, `chore:`).

## AI Workflow
- Prefer concise, clean code with TypeScript interfaces.
- Explain rationale briefly when proposing architectural changes.
