# Frontend Capstone Project

This repository hosts the capstone project for the Frontend AI Engineering track at FlyRank.

## Tech Stack
- React / Next.js
- Tailwind CSS
- TypeScript

## Setup
```bash
npm install
npm run dev

## Project Roadmap

1. **Foundation** — Set up the app structure, routing, and shared design styles.
2. **Core Experience** — Build the primary pages and user flows.
3. **Polish and Quality** — Refine responsive layouts, accessibility, and loading or error states.
4. **Release** — Verify the production build and deploy the finished project.

```
